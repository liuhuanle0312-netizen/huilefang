关于

绘乐坊

一个聚合多个图片生成中转站 API 的轻量工具。你自己添加中转站、填入在中转站申请的 Key，生成请求由浏览器直接发往你选的中转站，绘乐坊本身不提供模型、不经手你的 Key。所有生成的图片和记录都保存在你的账号里，换设备也能看到。

功能

  • 管理多个中转站
  • 支持各种 AI 模型

  • 实时生成进度

先在「模型接入」里添加你的 API Key，然后切到「图片生成」开始创作。

隐私说明

  • 你的 API Key 只保存在你自己的浏览器里，网站服务器和数据库都不经手、不上传。

常见问题

API Key 存在哪？

只存在你当前用的浏览器里。换浏览器、换手机或者清了缓存，都要重新填一次。

换设备能看到以前生成的图吗？

能。历史记录和图片存在云端账号里，登录同一个账号就能看到。但 API Key 不跟账号走，新设备要重新填 Key。

图片保存多久？

图片存在云端，不会自动删除。新图存在 R2，打开链接每次重新生成，不会过期；以前存在 Supabase 的旧图链接 7 天有效，过期后打开时会自动续一次；如果显示“图片已失效”，就是链接过期且续签失败了。

生成失败怎么办？

页面会用中文告诉你原因，比如 Key 不对、没开通这个模型、请求太频繁，按提示处理就行。

用这个网站要钱吗？

网站本身不收费。生图消耗的是你自己中转站 Key 的额度，用多少由你的中转站计费。

为什么有的图打不开？

有些中转站的图片链接不允许跨域下载，网站只能存个链接，链接过期后就打不开了。

详细说明

下面是完整的使用说明，遇到问题先来这里找答案，大部分情况都是正常现象。

一、怎么开始用
  • 第一次用先注册：填邮箱和密码，点验证邮件里的链接才能登录；登录要过一次人机验证。
  • 登录后先去「模型接入」添加中转站，填上你在中转站申请的 Key，保存后点一下测速，绿灯就是能用。
  • 再切到「图片生成」，选供应商和模型，写提示词，点生成；提示词框里按 Ctrl+Enter 也能直接生成。
  • 每次打开网站：7 天内来过就直接进；超过 7 天没打开，登录就失效了，要重新登录。
  • 换手机、换浏览器，或者清了缓存，供应商和 Key 都要重新填一遍；但以前生成的图还在账号里，登录就能看到。
二、生图时这些设置是真的有用的
  • 比例：选了哪个比例，图就是哪个尺寸；选「自动」就是让模型自己决定尺寸。
  • 画质：HD、FHD、QHD、4K 对应长边 1280、1920、2560、3840，越高越清晰、等得越久、也越容易失败。
  • 质量：低、中、高都会发给模型，高画质细节更好，但也更容易被上游拒绝。
  • 数量：一次最多出 8 张；勾了多模型对比时，每个模型各出 1 张，数量设置不起作用。
  • 参考图：最多传 5 张；有参考图时走另外的接口，输出格式那个选项就不起作用了。
  • 每个模型会记住你上次给它设的比例和画质，换模型不用重新调。
三、生成失败了怎么办
  • 先看页面报的中文原因：Key 不对、没开通这个模型、请求太频繁，都会直接写出来，按提示处理。
  • 报“提示词可能违规”，就是内容被上游拦了，换个说法再试，不要原样反复提交。
  • 4K 加高画质最容易失败：如果反复失败，先降到 QHD 或 FHD，或者把质量调低，成功了再往上加。
  • 报“网络出问题了”，是发往中转站的请求本身没通，检查一下网络，等网络好了再试，别连续点重试。
  • 注意：生成失败也可能扣费。中转站是按“提交请求”计费的，请求发到上游之后、哪怕上游中途失败，中转站也已经付过这次调用的钱了，一般不退；想核实就去中转站后台看消费记录，可以按请求编号查。
  • 建议先用小尺寸、低画质试一张，成功了再上大尺寸，避免白白扣费。
四、图片怎么保存、怎么防止丢失
  • 生成成功后图片会自动存到云端历史里，不用手动点保存，换设备登录也能看到。
  • 生成成功后记录立刻进历史，刷新也不会丢；图片文件在后台慢慢传，传好前卡片会显示“图片还没存好”，传好自动变清晰。网络断了也没事，下次打开网站会自动继续传；实在传不上来，卡片上会有「重新保存」按钮，点一下再存一次。
  • 生成过程中也别刷新或退出，图还在生成时刷新，费用照扣、图也拿不到。
  • 重要的图点卡片上的「下载」，会直接存到手机下载文件夹里，再从相册或文件管理里找；建议重要的图都下载一份留底，别只依赖云端历史。
  • 删图是真删除：历史卡片上的删除会把云端文件和记录一起删掉，删了找不回来，删之前想好。
  • 历史列表里显示的是小缩略图，看着有点糊是正常的，点开大图、下载、继续改用的都是原图。
  • 如果某张旧图显示「图片已失效」，一般是当初保存时只存了个中转站的临时链接，链接过期了；新图都存在云端，不会有这个问题。
五、这些都是正常现象，不用慌
  • 生成要等：普通尺寸几十秒，4K 可能要几分钟；进度条是模拟的，数字不代表真实进度，秒数才是真实等了多久。
  • 生成成功后提示词框会自动清空，是为了方便写下一条；想留着就生成前先复制一份。
  • 历史列表的图看着有点糊：列表用的是小缩略图，点开就是清晰原图。
  • 点历史图看大图时，会先显示一张小图顶着，原图下好立刻变清晰；刚进网站时滑到的图会在后台预先下载好，点开就是原图，不用等。
  • 第一次打开是登录页；7 天没打开要重新登录；登录框会帮你填好上次的邮箱。
  • 网站维护中时会暂停生成和注册，登录和看历史不受影响，横幅上有提示。
  • 网站上显示的余额不一定准，以中转站后台为准；中转站不提供余额接口，网站查不到实时余额。
  • 换设备后供应商和 Key 要重新填，历史记录不受影响。
六、账号、密码和费用
  • 密码至少 6 位；忘了密码点登录页的「忘记密码？」，验证邮件会发重设链接。
  • 注册后要点验证邮件里的链接才能登录；验证邮件每小时只有几封，没收到就等一会儿再重新发。
  • 开了二次验证的账号，每次登录密码过了还要输一次验证器 App 里的 6 位动态码。
  • 你的 Key 只存在你自己的浏览器里，网站不经手、不上传；不要把 Key 发给别人，泄露了去中转站后台换一个。
  • 网站本身不收费、不计费；扣费全是中转站的规则，生成失败也可能扣，见第三条。
  • 遇到问题先到这里找答案，找不到就点下面的「意见反馈」告诉站长，或者 QQ：168264129。

使用说明

1. 添加中转站
点「模型接入」→「＋ 添加中转站」，填名称（随便起，比如“吉吉”）、接口地址（比如 https://api.jiji.cc，结尾不要加 /v1，系统会自动补）和 API Key（从中转站网站复制），点保存。可以加多个中转站，Key 只存在这台手机的浏览器里。

2. 选供应商和模型
回到「图片生成」，先选供应商，再选模型。第一次用建议选 gpt-image-2.6-sunburst。

3. 写提示词
在提示词框里描述想要的画面，越具体越好，比如“一只橘猫坐在窗台上，下午阳光，写实照片”。

4. 选比例和画质
比例选自动（由模型决定）或想要的尺寸；画质分低、中、高，越高越清晰也越慢；比例不是自动时，还能再选 HD / FHD / QHD / 4K 档位。

5. 参考图（可选）
点「＋ 添加参考图」，最多 5 张，生成时会按参考图来改图。

6. 生成
点「生成」，等进度走完，图片就出现在下方的历史里。点开大图可以下载、复用提示词、继续改。

7. 历史和账号
生成过的图都存在云端，换手机登录后历史还在；但 API Key 只存在当前手机浏览器里，换手机要重新填。右上角头像可以改昵称和头像，月亮/太阳切换深色模式，左右滑动可以切换页面。
