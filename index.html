关于

绘乐坊

一个聚合多个图片生成中转站 API 的轻量工具。你自己添加中转站、填入在中转站申请的 Key，生成请求由浏览器直接发往你选的中转站，绘乐坊本身不提供模型、不经手你的 Key。所有生成的图片和记录都保存在你的账号里，换设备也能看到。

隐私说明

  • 你的 API Key 只保存在你自己的浏览器里，网站服务器和数据库都不经手、不上传。
  • 生成的图片和记录存在你的账号下，其他用户看不到。
  • 登录支持二次验证，账号更安全。

常见问题

API Key 存在哪？

只存在你当前用的浏览器里。换浏览器、换手机或者清了缓存，都要重新填一次。

换设备能看到以前生成的图吗？

能。历史记录和图片存在云端账号里，登录同一个账号就能看到。但 API Key 不跟账号走，新设备要重新填 Key。

图片保存多久？

图片存在云端，不会自动删除。新图存在 R2，打开链接每次重新生成，不会过期；以前存在 Supabase 的旧图链接 7 天有效，过期后打开时会自动续一次；如果显示“图片已失效”，就是链接过期且续签失败了。

生成失败怎么办？

页面会用中文告诉你原因，比如 Key 不对、没开通这个模型、请求太频繁，按提示处理就行。

用这个网站要钱吗？

网站本身不收费。生图消耗的是你自己中转站 Key 的额度，用多少由你的中转站计费。

为什么有的图打不开？

有些中转站的图片链接不允许跨域下载，网站只能存个链接，链接过期后就打不开了。

使用说明

1. 添加中转站
点「模型接入」→「＋ 添加中转站」，填名称（随便起，比如“吉吉”）、接口地址（比如 https://api.jiji.cc，结尾不要加 /v1，系统会自动补）和 API Key（从中转站网站复制），点保存。可以加多个中转站，Key 只存在这台手机的浏览器里。

2. 选供应商和模型
回到「图片生成」，先选供应商，再选模型。第一次用建议选 gpt-image-2.6-sunburst。

3. 写提示词
在提示词框里描述想要的画面，越具体越好，比如“一只橘猫坐在窗台上，下午阳光，写实照片”。

4. 选比例和画质
比例选自动（由模型决定）或想要的尺寸；画质分低、中、高，越高越清晰也越慢；比例不是自动时，还能再选 HD / FHD / QHD / 4K 档位。

5. 参考图（可选）
点「＋ 添加参考图」，最多 5 张，生成时会按参考图来改图。

6. 生成
点「生成」，等进度走完，图片就出现在下方的历史里。点开大图可以下载、复用提示词、继续改。

7. 历史和账号
生成过的图都存在云端，换手机登录后历史还在；但 API Key 只存在当前手机浏览器里，换手机要重新填。右上角头像可以改昵称和头像，月亮/太阳切换深色模式，左右滑动可以切换页面。
